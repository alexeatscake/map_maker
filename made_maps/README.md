# Generated Maps Directory

This directory contains the output files from the map generation process.

## Files Generated

- `base_map.csv` - Initial 40x40 terrain grid with smoothed biomes
- `big_key.csv` - Processed tile keys from the base map
- `expanded_map.csv` - Final detailed map with hex color data
- `expanded_map.png` - Visual PNG representation of the generated map

## Note

The contents of this directory are generated automatically by running the map maker scripts and are ignored by git to keep the repository clean.
